# Catalog gaps audit (2026-11-19)

Read-only audit of every reference catalog Soma Flight ships (aircraft types, airlines, airports, countries) and the assets paired with them (side views, tail fins, logos, flags, illustrations), cross-checked against the Supabase seed, the Rust core, the web app and the local `aircraft-art/` pipeline. Nothing was changed. The owner decides what to fill.

Rerun: `python3 docs/audits/2026-11-19-catalog-gaps.py` (text) or `--json`. See [How to rerun](#how-to-rerun).

## Where the catalogs live

| Catalog | Source of truth in the app | Shared with | Paired assets |
|---|---|---|---|
| Aircraft types | `Resources/Reference/aircraft_types.json` | Supabase `aircraft_types` (seed csv + `20261109000001_business_jets.sql`) | `Resources/SideViews/*.webp` + `index.json` (`<AIRLINE>-<TYPE>`, `ZZZ-<TYPE>` = plain view), `aircraft-art/ai` renders, `aircraft-art/silhouette` |
| Airlines | `Resources/Reference/airlines.json` | Supabase `airlines` (seed csv + 3 migrations), web (`Apps/Web/src/ui/airlines.ts` imports the same file) | `Resources/Logos` + `commons-logos.json`, `Resources/Licenses/airline-logos.json`, `Resources/Tails/tail-<ICAO>.webp`, side views, `livery_seed.json`, `airline_contacts.json`, `Services/AirlineParents.swift` |
| Airports | `Resources/Reference/airports.tsv` | Supabase `airports` (`20261028000002_airports_seed.sql`), web (`airports.ts` imports the same file) | `airport_sizes.json`, `connection_rules.json` |
| Countries | `Resources/Reference/countries.json` | Supabase `country_regions.csv` | `Resources/Flags.xcassets` (`flag-<iso2>`, `flag-xx` neutral), `destinations.json` |

The Rust core (`core/flightcore`) holds no catalog: it only takes family strings (`aircraft.rs` seat maps). The web app reads the Swift reference files directly through the `@flightkit` alias, so the web cannot drift on data; it shows no logos, side views, tails or flags at all (monogram only, by design in `AirlineMark.tsx`).

## How to rerun

From the repo root (needs Python 3.10+, Pillow, numpy; reads only):

```bash
python3 docs/audits/2026-11-19-catalog-gaps.py
```

```bash
python3 docs/audits/2026-11-19-catalog-gaps.py --json > /tmp/catalog-gaps.json
```

The `aircraft-art/` checks (V3, D3, D4, X9) run only on a machine that has the git-ignored `aircraft-art/` folder. The pixel checks (X4, X5) are heuristics: mean saturation under 6 or a single RGB colour; review them by eye. V1 compares `airports.tsv` against the `icao_code` column of `supabase/seed/airports.csv`.
